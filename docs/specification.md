## 1. アプリケーション概要

| 項目               | 内容                  |
| ------------------ | --------------------- |
| アプリケーション名 | Kore Motta?           |
| ドメイン           | kore-motta.kem198.net |

「Kore Motta?」は、日常的な持ち物や確認事項を繰り返し管理するためのシンプルな Todo ウェブアプリケーションである。

- ユーザーは、Todo を登録して毎日確認し、完了したものをチェックできる。
- 日付が変わると、すべての Todo が未完了に戻る。
- 上記の機能により、同じ Todo を繰り返し利用できる。

## 2. 設計方針

- 小規模なアプリケーションとして [YAGNI 原則](https://ja.wikipedia.org/wiki/YAGNI) に従い、必要以上に複雑な機能や設計を導入しない。
- 初回リリースでは、ユーザーが Todo を確認して完了するという主要なユースケースを優先する。
- 将来機能は、必要性を確認してから実装する。

## 3. 用語の定義

開発中は「開発用語」を使用し、ユーザー向けの画面や文章では「ユーザー向け表現」を使用する。

表に含まれていない表現や、ユーザー向けの文章に登場する場合は、文脈に応じて適切な表現を使用する。

| 開発用語         | ユーザー向け表現         | 定義                                               |
| ---------------- | ------------------------ | -------------------------------------------------- |
| Todo             | アイテム                 | ユーザーが繰り返し確認・実行する項目               |
| 未完了状態       | 未完了                   | Todo が完了していない状態                          |
| 完了状態         | 完了済み                 | Todo が完了している状態                            |
| カテゴリ         | カテゴリ                 | Todo を分類する単位                                |
| 選択中のカテゴリ | 選択中のカテゴリ         | ユーザーが現在表示しているカテゴリ                 |
| 日次未完了化時刻 | 未完了に戻す時刻         | Todo を未完了に戻す基準時刻                        |
| 日次未完了化     | すべて未完了に戻る       | 日付が変わった際にすべての Todo を未完了にする処理 |
| 手動未完了化     | 手動ですべて未完了に戻す | ユーザー操作ですべての Todo を未完了にする処理     |
| 最終未完了日時   | すべて未完了に戻した日時 | すべての Todo を未完了にした最新の日時             |
| 保存済みデータ   | 登録した内容             | Todo やカテゴリなど、ユーザーが登録した情報        |

## 4. 主要機能

### 4.1. Todo

ユーザーは、Todo を登録して管理できる。

Todo には以下の情報を設定できる。

| プロパティ  | 必須 | 説明                         |
| ----------- | ---- | ---------------------------- |
| タイトル    | Yes  | Todo の名称                  |
| メモ        | No   | Todo の補足情報              |
| 完了状態    | Yes  | 完了または未完了             |

ユーザーは Todo に対して、以下の操作ができる。

- 作成
- 確認
- 編集
- 削除
- 完了状態の変更
- 所属しているカテゴリの変更

ユーザーが Todo を新規作成すると、選択中のカテゴリに追加される。

Todo を新規作成した場合、選択中のカテゴリへ追加する。

### 4.2. カテゴリ

ユーザーは、Todo をカテゴリに分類して管理できる。

カテゴリには以下の情報を設定できる。

| プロパティ | 必須 | 説明                  |
| ---------- | ---- | --------------------- |
| タイトル   | Yes  | カテゴリの名称        |

ユーザーはカテゴリに対して、以下の操作ができる。

- 作成
- 確認
- 編集
- 削除
- 選択

アプリケーションの初期カテゴリとして「未分類」カテゴリが用意される。  
「未分類」カテゴリは編集・削除できない。

### 4.3. 日次未完了化

ユーザーは、同じ Todo を日単位で繰り返し利用できる。

- 日付が変わると、すべての Todo が未完了に戻る。
- Todo のタイトル、メモ、カテゴリなどは維持される。
- Todo が未完了に戻った後、すべて未完了に戻した日時が更新される。
- 未完了に戻す時刻は 00:00 に固定する。
- カテゴリに関係なく、すべての Todo が未完了に戻る。

## 5. 周辺機能

### 5.1. データのエクスポート・インポート

ユーザーは、保存済みデータを JSON 形式でエクスポート・インポートできる。

- ユーザーは保存済みデータをバックアップとして保存できる。
- ユーザーはバックアップした内容をインポートして復元できる。
- ユーザーは別のブラウザへ保存済みデータを移行できる。

### 5.2. アプリインストール

ユーザーは、対応端末にアプリケーションをインストールして、アプリとして利用できる。

実現には [PWA](https://developer.mozilla.org/ja/docs/Web/Progressive_web_apps) を利用する。

### 5.3. ヘルプ・規約

ユーザーは以下を確認できる。

- 使い方
- 利用規約
- アプリのインストール手順
