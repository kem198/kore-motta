## 1. アプリケーション概要

| 項目               | 内容                  |
| ------------------ | --------------------- |
| アプリケーション名 | Kore Motta?           |
| ドメイン           | kore-motta.kem198.net |

「Kore Motta?」は、日常的な持ち物や確認事項を繰り返し管理するためのシンプルな Todo ウェブアプリケーションである。

- Todo の作成・確認・編集・削除、完了状態の変更、カテゴリ管理を提供する。
- Todo は繰り返し利用することを前提とし、日付が変わるとすべて未完了に戻る。

## 2. 設計方針

- 小規模なアプリケーションとして [YAGNI 原則](https://ja.wikipedia.org/wiki/YAGNI) に従う。必要以上に複雑な機能や設計を導入しない。
- 初回リリースでは、Todo の確認と完了という主要ユースケースを優先する。
- 将来機能は、必要性を確認してから実装する。

## 3. 用語の定義

下記の表現を開発中やユーザー向けの表現として利用する。

表に含まれていないものや、冗長になる場合、ユーザー向けの文章に登場する場合は、適宜文脈に沿った表現を行う。

| 開発用語         | ユーザー向け表現         | 定義                                     |
| ---------------- | ------------------------ | ---------------------------------------- |
| Todo             | アイテム                 | 繰り返し確認・実行する項目               |
| 未完了状態       | 未完了                   | Todo が完了していない状態                |
| 完了状態         | 完了済み                 | Togo が完了している状態                  |
| カテゴリ         | カテゴリ                 | Todo を分類する単位                      |
| 選択中のカテゴリ | 選択中のカテゴリ         | 現在表示しているカテゴリ                 |

## 4. 主要機能

### 4.1. Todo

Todo は以下の情報を持つ。

| プロパティ  | 必須 | 説明                         |
| ----------- | ---- | ---------------------------- |
| ID          | Yes  | Todo の ID                   |
| タイトル    | Yes  | Todo の名称                  |
| メモ        | No   | Todo の補足情報              |
| 完了状態    | Yes  | 完了または未完了             |
| カテゴリ ID | Yes  | Todo が所属するカテゴリの ID |

Todo には以下の操作を提供する。

- 作成
- 確認
- 更新
- 削除
- 完了状態の変更
- 所属するカテゴリの変更

Todo は「完了」と「未完了」の状態を持つ。チェックによって完了状態を変更できる。

### 4.2. カテゴリ

Todo はカテゴリに分類できる。

カテゴリは以下の情報を持つ。

| プロパティ | 必須 | 説明           |
| ---------- | ---- | -------------- |
| ID         | Yes  | カテゴリの ID  |
| タイトル   | Yes  | カテゴリの名称 |

カテゴリには以下の操作を提供する。

- 作成
- 確認
- 更新
- 削除
- 選択

Todo には以下のカテゴリ操作を提供する。

- 選択中のカテゴリへの追加
- 別カテゴリへの移動

### 4.3. 日次未完了化

Todo は日単位で繰り返し利用する。

- 動作環境のローカル日時で 00:00 をまたいだことを検出すると、すべての Todo を未完了に戻す。
- 日次未完了化では完了状態のみを変更し、それ以外の情報は維持する。
- 未完了にした後は最終未完了日時を更新する。
- 初回リリースでは、カテゴリに関係なくすべての Todo を一括してリセットする。
