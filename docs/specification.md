## 1. アプリケーション概要

### 1.1 基本情報

| 項目               | 内容                        |
| ------------------ | --------------------------- |
| アプリケーション名 | これ、もった？              |
| 英名               | Kore Motta?                 |
| ドメイン           | kore-motta.kem198.net       |
| 種別               | Todo ウェブアプリケーション |

### 1.2 コンセプト

「これ、もった？」は、日常的な持ち物や確認事項を管理するための、小規模でシンプルな Todo ウェブアプリケーションである。

基本的な Todo の CRUD 機能とカテゴリ管理機能を提供する。

Todo は毎日繰り返し利用することを前提とし、ユーザーが設定した時刻になると、すべての Todo が自動的に未完了状態へ戻る。

### 1.3 設計上の基本方針

本アプリケーションは小規模な Todo アプリケーションであるため、必要以上に複雑な機能や設計を導入しない。

実装は YAGNI 原則に従い、使うかわからない余分な機能およびコードはなるべく最小限にする。

初期リリースでは、毎日使う Todo を簡単に確認し、完了させるという主要なユースケースを優先する。

将来対応の機能は、必須機能の実装・動作確認が完了した後に、必要性を判断して実装する。

## 2. Todo

### 2.1 Todo のデータ

1 つの Todo は、以下の情報を持つ。

| プロパティ | 必須 | 説明                                |
| ---------- | ---- | ----------------------------------- |
| タイトル   | Yes  | Todo の名称                         |
| メモ       | No   | Todo に関する補足情報               |
| 絵文字     | No   | Todo を視覚的に識別するための絵文字 |
| 完了状態   | Yes  | 完了または未完了                    |
| カテゴリ   | No   | Todo が所属するカテゴリ             |

### 2.2 Todo の操作

Todo に対して、以下の操作を提供する。

- 作成
- 取得
- 編集
- 削除

### 2.3 完了状態

Todo は「完了」と「未完了」の状態を持つ。

Todo をチェックすることで、完了状態へ変更できる。

完了状態は一覧画面または編集画面から変更できる。

### 2.4 絵文字

Todo には絵文字を設定できる。

設定した絵文字は Todo の一覧画面に表示する。

## 3. カテゴリ

Todo はカテゴリによって分類できる。

### 3.1 カテゴリ管理

カテゴリに対して、以下の操作を提供する。

- カテゴリを追加できる
- カテゴリを編集できる
- カテゴリを削除できる
- カテゴリを選択できる

### 3.2 Todo とカテゴリ

Todo はカテゴリに所属させることができる。

以下の操作を提供する。

- Todo を選択中のカテゴリへ追加できる
- Todo を別のカテゴリへ移動できる

## 4. 日次リセット

### 4.1 基本仕様

Todo は日単位で繰り返し利用する。

1 日に 1 回、設定されたリセット時刻になると、すべての Todo の完了状態を自動的に「未完了」へ戻す。

リセット後も Todo 自体は削除されず、同じ Todo をその日の Todo として再利用できる。

### 4.2 リセット時刻

Todo をリセットする時刻はユーザーが設定できる。

例:

- 00:00
- 04:00
- 06:00

### 4.3 リセット対象

日次リセットで変更するのは Todo の完了状態のみとする。

以下の情報は維持する。

- タイトル
- メモ
- 絵文字
- カテゴリ

完了状態のみ、すべて「未完了」へ戻す。

### 4.4 手動リセット

ユーザーが任意のタイミングで Todo を手動リセットできる。

## 7. 実装優先度

各機能の実装優先度を以下の 2 段階で定義する。

### 7.1 必須機能

初期リリースに必要な機能。

#### Todo

- Todo を作成できる
- Todo を確認できる
- Todo を編集できる
- Todo を削除できる
- Todo をチェックして完了できる

#### カテゴリ

- Todo をカテゴリ分けできる
- カテゴリを追加できる
- カテゴリを編集できる
- カテゴリを削除できる
- カテゴリを選択できる
- Todo を選択中のカテゴリへ追加できる
- Todo を別のカテゴリへ移動できる

#### 日次リセット

- Todo をリセットする時刻を設定できる
- Todo が設定時刻に自動でリセットされる
- リセット時に Todo の完了状態が未完了へ戻る
- リセット時に Todo の内容は維持される

#### アプリケーション

- アプリとしてインストールできる
- 使い方を確認できる
- 利用規約を確認できる

### 7.2 将来対応

初期リリースでは必須とせず、必要性を判断して後から実装する機能。

#### UI / 表示

- ダークモードに変更できる
- Todo が完了したら一覧の末尾へ移動する
- ボタンの並びを使いやすくする
- 追加ボタンや編集ボタンを左側へ移動できる
- Todo のメモへ長文を入力した際の表示崩れを修正する

#### Todo 操作

- Todo に絵文字を設定できる
- Todo 本体をクリックすると編集できる
- Todo 編集時、更新ボタンを押さなくても自動的に更新される
- Todo をつまんで移動できる
- Todo を手動でリセットできる

#### フィードバック

- すべての Todo を完了した際に confetti で祝う

#### 編集モード

- 編集モード中に追加ボタンを押せないことを分かりやすくする
- または、編集モード中でも Todo を追加できるようにする
