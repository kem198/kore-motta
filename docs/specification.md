## 2. アプリケーション概要

### 2.1. 基本情報

| 項目               | 内容                        |
| ------------------ | --------------------------- |
| アプリケーション名 | Kore Motta?                 |
| ドメイン           | kore-motta.kem198.net       |
| 種別               | Todo ウェブアプリケーション |

### 2.2. コンセプト

「Kore Motta?」は、日常的な持ち物や確認事項を管理するための、小規模でシンプルな Todo ウェブアプリケーションである。

基本的な Todo の CRUD 機能とカテゴリ管理機能を提供する。

Todo は毎日または隔日で繰り返し利用することを前提とし、ユーザーが設定した時刻になると、すべての Todo が自動的に未完了状態へ戻る。

### 2.3. 設計上の基本方針

本アプリケーションは小規模な Todo アプリケーションであるため、必要以上に複雑な機能や設計を導入しない。

実装は YAGNI 原則に従い、使うかわからない余分な機能およびコードはなるべく最小限にする。

初期リリースでは、毎日使う Todo を簡単に確認し、完了させるという主要なユースケースを優先する。

将来対応の機能は、必須機能の実装・動作確認が完了した後に、必要性を判断して実装する。

## 3. Todo

### 3.1. Todo のデータ

1 つの Todo は、以下の情報を持つ。

| プロパティ | 必須 | 説明                    |
| ---------- | ---- | ----------------------- |
| タイトル   | Yes  | Todo の名称             |
| メモ       | No   | Todo に関する補足情報   |
| 完了状態   | Yes  | 完了または未完了        |
| カテゴリ   | Yes  | Todo が所属するカテゴリ |

### 3.2. Todo の操作

Todo に対して、以下の操作を提供する。

- 作成
- 取得
- 編集
- 削除

### 3.3. 完了状態

Todo は「完了」と「未完了」の状態を持つ。

Todo をチェックすることで、完了状態へ変更できる。

完了状態は一覧画面または編集画面から変更できる。

## 4. カテゴリ

Todo はカテゴリによって分類できる。

### 4.1. カテゴリ管理

カテゴリに対して、以下の操作を提供する。

- カテゴリを追加できる
- カテゴリを編集できる
- カテゴリを削除できる
- カテゴリを選択できる

### 4.2. Todo とカテゴリ

Todo はカテゴリに所属させることができる。

以下の操作を提供する。

- Todo を選択中のカテゴリへ追加できる
- Todo を別のカテゴリへ移動できる

## 5. 日次リセット

### 5.1. 基本仕様

Todo は日単位で繰り返し利用する。

1 日に 1 回、00:00 をまたぐとすべての Todo の完了状態を自動的に「未完了」へ戻す。

リセット後も Todo 自体は削除されず、同じ Todo をその日の Todo として再利用できる。

### 5.2. リセット対象

日次リセットで変更するのは Todo の完了状態のみとする。

以下の情報は維持する。

- タイトル
- メモ
- カテゴリ

完了状態のみ、すべて「未完了」へ戻す。

更新後は最終未完了日時を更新する。

### 5.3. 手動リセット

ユーザーが任意のタイミングで Todo を手動リセットできる。

### 5.4. リセットの単位

リセットの単位はカテゴリをまたいだ Todo すべてとする。

初回リリース後、カテゴリごとのリセット日時設定とリセットを検討する。

## 8. 実装優先度

各機能の実装優先度を以下の 3 段階で定義する。

### 8.1. 優先度: 高 (必須機能)

初期リリースに必要な機能。

#### 8.1.1. Todo

- Todo を作成できる
- Todo を確認できる
- Todo を編集できる
- Todo を削除できる
- Todo をチェックして完了できる
- Todo 本体をクリックすると編集できる

#### 8.1.2. カテゴリ

- Todo をカテゴリ分けできる
- カテゴリを追加できる
- カテゴリを編集できる
- カテゴリを削除できる
- カテゴリを選択できる
- Todo を選択中のカテゴリへ追加できる
- Todo を別のカテゴリへ移動できる
- カテゴリを一覧表示できる
- ページを開いたとき、最後に選択していたカテゴリを表示できる

#### 8.1.3. 日次リセット

- リセット時刻を 00:00 に固定する
- ページを再読み込みした時に日次リセットを判定する
- Todo が自動的に未完了へ戻る
- リセット時に Todo の内容を維持する
- Todo を手動ですべて未完了に戻せる

#### 8.1.4. PWA

- アプリとしてインストールできる
- 使い方を確認できる
- 利用規約を確認できる
- アプリとしてインストールする手順がわかる

#### 8.1.5. データ保護

- ローカルストレージ上の情報が壊れている時、ダイアログでバックアップを促した上で情報を初期化する

### 8.2. 優先度: 中

初期リリースでは必須とせず、必要性を判断して後から実装する機能。

#### 8.2.1. 日次リセット

- ページがアクティブでなくなった後、復帰した時にも日次リセットを判定する
- Todo をリセットする時刻をカテゴリごとに設定できる

#### 8.2.2. Todo 操作

- Todo が完了したら一覧の末尾へ移動する
- Todo 編集後、更新ボタンを押さなくても自動的に更新する
- Todo をつまんで動かせる

### 8.3. 優先度: 低

#### 8.3.1. UI / 表示

- すべての Todo を完了したことがわかりやすいようにする
- スマートフォンで入力した際、追加された Todo が表示領域外へ移動して見づらくなる問題を改善する
- ダークモードに変更できる
- インポート時にダイアログを表示する

#### 8.3.2. カテゴリ

- カテゴリの並び替えができる
