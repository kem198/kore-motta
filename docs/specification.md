## 1. アプリケーション概要

### 1.1. 基本情報

| 項目               | 内容                        |
| ------------------ | --------------------------- |
| アプリケーション名 | Kore Motta?                 |
| ドメイン           | kore-motta.kem198.net       |
| 種別               | Todo ウェブアプリケーション |

### 1.2. コンセプト

「Kore Motta?」は、日常的な持ち物や確認事項を管理するための、小規模でシンプルな Todo ウェブアプリケーションである。

基本的な Todo の CRUD 機能とカテゴリ管理機能を提供する。

Todo は毎日または隔日で繰り返し利用することを前提とし、日付をまたいだタイミングですべての Todo が自動的に未完了状態へ戻る。

### 1.3. 設計上の基本方針

- 本アプリケーションは小規模な Todo アプリケーションであるため、必要以上に複雑な機能や設計を導入しない。
- 実装は YAGNI 原則に従い、使うかわからない余分な機能およびコードはなるべく最小限にする。
- 初回リリースでは、毎日使う Todo を簡単に確認し、完了させるという主要なユースケースを優先する。
- 将来対応の機能は、必須機能の実装・動作確認が完了した後に、必要性を判断して実装する。

## 2. Todo

### 2.1. Todo のモデル

1 つの Todo は、以下の情報を持つ。

| プロパティ | 必須 | 説明                    |
| ---------- | ---- | ----------------------- |
| タイトル   | Yes  | Todo の名称             |
| メモ       | No   | Todo に関する補足情報   |
| 完了状態   | Yes  | 完了または未完了        |
| カテゴリ   | Yes  | Todo が所属するカテゴリ |

### 2.2. Todo の操作

Todo に対して、以下の操作を提供する。

- 作成
- 取得
- 編集
- 削除

### 2.3. 完了状態

Todo の完了状態を次の通り定義する。

- Todo は「完了」と「未完了」の状態を持つ。
- Todo をチェックすることで、完了状態へ変更できる。
- 完了状態は一覧画面または編集画面から変更できる。

## 3. カテゴリ

Todo はカテゴリによって分類できる。

### 3.1. カテゴリ管理

カテゴリに対して、以下の操作を提供する。

- カテゴリを追加できる
- カテゴリを編集できる
- カテゴリを削除できる
- カテゴリを選択できる

### 3.2. Todo とカテゴリ

Todo はカテゴリに所属させることができる。

以下の操作を提供する。

- Todo を選択中のカテゴリへ追加できる
- Todo を別のカテゴリへ移動できる

## 4. 日次リセット

### 4.1. 基本仕様

- Todo は日単位で繰り返し利用する。
- 動作環境のローカル日時で 00:00 をまたぐと、すべての Todo の完了状態を自動的に「未完了」へ戻す。
- 未完了へ戻した後も Todo 自体は削除されず、同じ Todo をその日の Todo として再利用できる。

### 4.2. リセット対象

日次リセットで変更するのは Todo の完了状態のみとする。

以下の情報は維持する。

- タイトル
- メモ
- カテゴリ

完了状態のみ、すべて「未完了」へ戻す。

更新後は最終未完了日時を更新する。

### 4.3. 手動リセット

ユーザーが任意のタイミングで Todo を手動リセット (未完了に戻す) できる。

### 4.4. リセットの単位

初回リリースでのリセットの単位は、カテゴリをまたいだ Todo すべてとする。

初回リリース後、カテゴリごとのリセット日時設定とリセットを検討する。
